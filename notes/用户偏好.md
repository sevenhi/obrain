# 用户偏好设置

## 界面与交互
- **语言**: 中文 (zh-CN)
- **Hermes Dashboard**: 绑定 0.0.0.0 (LAN 访问)，使用 `hermes-dash` 别名
- **认证**: Basic Auth (admin + 配置文件密码)
- **主要交互方式**: Hermes TUI 终端、WeChat Gateway、飞书 Gateway
- **不使用**: Hermes Desktop (Electron)、Hermes Dashboard (Web 面板)

## 文件管理
- **Hermes 相关文件**: 统一放在 `~/workspace/hermes/` 下
- **新项目文件**: 统一放在 `~/workspace/` 下的独立子文件夹
- **不污染**: Home 目录 (`~/`)

## 自动化原则
- **核心原则**: 只关设备，不开设备 ("人来灯亮"归 HA/小爱管)
- **Miloco rule**: `on_enter_actions` 必须为空
- **无人关设备**: `duration_seconds=900` (15min), `exit_debounce_seconds=30`
- **设备例外** (不在无人自动关规则中):
  - 除湿机
  - 空气净化器
  - 摄像头
  - 网关/路由器
  - 服务器/NAS

## 服务配置
- **所有 Web 前端服务**: 绑定 0.0.0.0 (LAN 可达)，systemd 自动启动
- **Hermes API Server**: 端口 8642, host 0.0.0.0, 模型 hermes-agent
- **视觉辅助**: SiliconFlow Qwen3-VL-8B-Instruct (免费模型)

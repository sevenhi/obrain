# Task Instructions

| Notes | Modification Date | Approved By |
|:--|:--|:--|
| Initial Document | August 23, 2026 | 詹彬 |

## Rules
- Title: Imperative verb + task (e.g., "Fix gutter").
- Status: Must always be set: `[open]`, `[in-progress]`, `[blocked]`, `[done]`.
- Archiving: When `[status] done`, append completion date and move to archive (if using).

## Observations
- [convention] Every task requires status observation.
